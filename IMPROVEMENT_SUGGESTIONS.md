# Предложения по улучшению Flutter приложения "Личный кабинет студента"

*Анализ проведен: 30 мая 2026*

## 🏗️ **Архитектурные улучшения**

### 1. **Внедрение BLoC/Cubit вместо Provider**
Текущее использование Provider с большими State классами создает проблемы:
- `StudentAppState` содержит 500+ строк кода (lib/state/student_app_state.dart)
- Смешивает бизнес-логику с UI состоянием
- Сложно тестировать отдельные части

**Предложение**: Разделить на отдельные BLoC'и:
```dart
// Вместо одного большого StudentAppState
AuthBloc, ScheduleBloc, GradesBloc, ProfileBloc
```

### 2. **Улучшение Repository Pattern**
Текущие репозитории хорошо структурированы, но можно добавить:
- Интерфейсы для всех репозиториев
- Dependency Injection (get_it)
- Лучшее разделение между локальными и удаленными источниками данных
